# 展示主页重构

## 目标

抛弃旧的全屏三面板实现，重新设计并重写必应美图档案主页：沉浸式全屏浏览 2023 年至今的全部每日壁纸。

## 修改范围

- `index.html`：重写语义化骨架（顶栏 / 双层主图舞台 / 底部缩略图时间轴）
- `src/main.ts`：全部重写（数据层、舞台渲染、窗口化时间轴、多输入导航、hash 同步）
- `src/style.css`：全部重写（深色沉浸式视觉、毛玻璃、动画、响应式、无障碍）
- `vite.config.ts`：新增（内联动态导入，产物自包含）

## 核心实现

### 数据层（不再依赖 script/data.json）

- `import.meta.glob("../image/*/data.json")` 构建期打包全部单日数据（1007 份，~700KB）
- 日期索引从 glob 键提取，反映磁盘真实状态；旧 `script/data.json` 索引含一条无数据残留（20250103），已自然规避
- 图片一律走远程 Bing URL：主图 `urlbase + _UHD.jpg&qlt=100`（实测 200），缩略图 `urlbase + _640x360.jpg`（实测 200，约 40KB；`_192x108` 等规格已实测 404 弃用）

### 交互

- 滚轮（主图区切换，带累积阈值 60px + 700ms 冷却防触摸板连跳）、触摸滑动、键盘（←→↑↓/PageUp/PageDown/Home/End）
- 缩略图时间轴：窗口化虚拟列表（可视区 ±24 缓冲），绝对定位 + transform，点击跳转、主图切换自动居中
- URL 路径直达（`/20260529`，history 模式），支持浏览器前进/后退；兼容旧 `#20260529` 链接（自动迁移为路径）
- 预取相邻 ±1 详情与主图、±2 详情
- 新增展示信息：版权行旁「图片测验」按钮（Bing 官方 quiz 链接，100% 存在）；顶栏显示精确展示时间（fullstartdate，格式 `YYYY-MM-DD HH:mm UTC`）
- 用户友好设计：
  - 左右箭头按钮（桌面端 hover 舞台浮现，首尾自动禁用）
  - 顶栏「随机」「最新」按钮（一键回最新一天 / 随机漫游）
  - 时间轴按年份分组标签（2023~2026，点击跳转该年）+ 鼠标拖拽滚动（拖拽超阈值抑制误触点击）
  - 首次访问操作提示 toast（6 秒自动消失，localStorage 记忆，隐私模式静默跳过）
  - 主图切换下载超 300ms 时右下角加载指示，避免"点了没反应"错觉
- 闲时预载：切换时即时预取相邻 ±1 主图；浏览器空闲时（requestIdleCallback）从 ±2 向外扩展预载，**总量上限 10 张**（UHD 约 5MB/张，控制带宽）；页面停帧导致 timeRemaining 恒为 0 时每轮仍至少处理 1 张防饿死，重调度 1 秒兜底
- **预载开关**：预载约 5MB/张、流量开销大，是否启用由用户决定——顶栏「预载」按钮切换（开启态 accent 高亮），localStorage 记忆，**默认关闭**；关闭时即时预取与闲时预载均不执行，切换按需下载，零预载流量
- 无障碍优化：
  - 主图 img alt 置空（装饰性背景），标题由 caption 的 h2（lang="en"）朗读，消除重复播报；版权行 lang="en"
  - 时间轴语义修正：容器 role="group"、缩略图 aria-current 标记当前项（替代与 button 冲突的 listbox/option/aria-selected）
  - 时间轴 roving tabindex：仅当前项可 Tab 聚焦，焦点在时间轴内时方向键在缩略图间移动、Home/End 跳首末（自动滚动挂载目标）
  - 顶栏「随机」「最新」补充 title 说明；time-display 对比度 0.52→0.68；quiz-btn 与顶栏按钮触摸目标增大（padding 8px）

### 状态与容错

- 首屏加载遮罩 / 数据加载失败可重试 / 主图失败占位（alt 可读）/ 缩略图失败保留日期角标
- 快速连按时通过 `pendingIndex` 令牌丢弃过期请求，避免错乱

## 影响范围

- 前端三件套 + 新增 vite.config.ts；不涉及 `script/` 抓取脚本与 CI
- 构建产物自包含（index.html + 1 个 JS + 1 个 CSS），部署只需 dist；站点根不再需要 `image/`、`script/` 目录
- JS 1.05MB（gzip 186KB），首屏体积增大换取零运行时数据请求

## 验证方式

- `pnpm build`（tsc 严格模式 + vite）通过
- headless Chrome 实测：首屏渲染最新一图（标题/日期/计数/版权链接正确）、`#20231119` hash 直达、390x844 移动端视口、缩略图远程图实际加载成功
- Node 自测：数据解析、日期升序、无重复、URL 编码

## 已知限制

- **history 模式部署要求**：刷新/直达任意日期路径依赖服务器 SPA fallback（任意路径回退到 index.html）。vite dev/preview 已内置；生产环境需配置，例如 Nginx `try_files $uri /index.html;`，或 Apache `RewriteRule ^ /index.html [L]`。若不配置，直接访问 `/20260529` 会 404（从根路径进入后站内跳转不受影响）
- 图片强依赖 cn.bing.com 可达性（主图失败仅显示占位，无本地降级——按需求图片不走本地）
- 时间轴缩略图仅日期角标占位时（远程缩略图失败）视觉信息量下降，但导航功能完整
- 构建警告 chunk >500KB 属预期（全量数据内联），可后续用 codeSplitting 拆分为数据包
